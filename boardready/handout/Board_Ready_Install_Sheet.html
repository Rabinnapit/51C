Get the app in one minute

The page that opens has one job: put the app on your phone. No app store, no account, no cost.

https://rabinnapit.github.io/51C/boardready/

iPhone (Safari)

  1. Scan the code with the Camera app: the page opens in Safari.
  2. Tap Share (the square with an arrow) in the bar at the bottom. If that bar shows ···, tap it first.
  3. Tap Add to Home Screen, then Add.
  4. Open it from the new icon once while online.

Android (Chrome)

  1. Scan the code with the Camera app.
  2. Tap Install app. If the page opened in Samsung Internet, tap Install with Chrome first: only Chrome installs it without a warning.
  3. Tap Install in the box that appears.
  4. Open it from the new icon once while online.
